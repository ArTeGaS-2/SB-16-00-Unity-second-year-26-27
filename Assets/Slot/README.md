# Lucky Cats — слотмашина

Готова машина вже стоїть біля Player у SampleScene. Префаб: `Prefabs/RetroSlotMachine.prefab`.

- Навести центр камери на машину з відстані до 3,5 м і натиснути **E**.
- Спіни безкоштовні, кількість спроб необмежена. Під час обертання повторний запуск блокується.
- Два однакові символи: **3** монети; три однакові: **10**; три сімки: **20**.
- Виграш видається фізичними монетами з машини. Кожна має випадковий матеріал із 100 котів, тег **Object**, Rigidbody і BoxCollider.
- Gravity gun проєкту: ЛКМ — підхопити/кинути, ПКМ — відпустити; коліщатко — відстань, середня кнопка — обертання.

Два скрипти: `SlotPlayerInteractor` на персонажі, `SlotMachine` на машині. Для іншого персонажа додати `SlotPlayerInteractor` та вказати його камеру; префаб машини вже містить усі власні посилання.

Символи барабанів узяті з наданого Slots.rar; 100 унікальних котячих зображень випадково вибрані з cats_from_memes.zip. Код із архіву не використовується. Геометрія корпусу доопрацьована у Blender; матеріали розраховані на URP.
